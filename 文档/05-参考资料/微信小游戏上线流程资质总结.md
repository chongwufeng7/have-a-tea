# 微信小游戏上线流程资质总结

> 整理日期：2026-09-10。适用方向：个人主体、独立开发、以广告变现为主的微信小游戏（IAA），不接虚拟支付。
> 本文依据本次对话中用户提供的微信官方文档、腾讯客服页面及截图整理。未确认的项目单独列出；实际办理以当前后台要求和审核结果为准。

## 一、结论

- 微信小游戏支持个人注册，符合条件的个人可以开通广告变现；协议明确包含个人结算规则。
- 个人微信认证审核费已确认是 **30元／次**，不是企业认证说明中的300元。不能据此认定完整上线成本只有30元。
- 普通休闲类、纯广告游戏，并非一律必须提交软著或版号；需要结合实际类目、名称、内容和授权情况判断。
- 无版号纯广告路线需要办理小游戏备案，并继续完成小程序备案。
- 流量主可通过不同条件开通，不一定必须先积累超过500名独立访客。
- 可以开始开发，不必等待全部手续结束。需要先做出内容基本确定、能真实截图的版本，再提交相应游戏内容材料。

## 二、上线与变现主流程

1. 注册微信公众平台账号：账号类型选择“小程序”，类目选择“小游戏”，主体选择“个人”。
2. 完善游戏名称、简称、头像和实际玩法对应的三级类目。
3. 完成微信认证、适龄提示设置、资质提交与审核。
4. 提交小游戏备案：介绍场景、玩法、功能，上传对应版本截图，并完成要求的签署文件等。
5. 小游戏备案等前置事项及微信认证完成后，办理小程序备案。
6. 提交游戏版本审核；官方流程说明版本审核与小程序备案可并行提交。
7. 满足发布要求、审核通过后，正式发布小游戏。
8. 满足任一流量主开通路径后，申请开通，配置广告位并完成广告接入与测试。
9. 若广告接入涉及版本更新，重新提审并发布；观察真实有效广告收入，按后台规则结算。

**顺序说明：**上述为项目安排，不表示流量主只能在正式发布之后申请。现有截图未明确其最早开放阶段，实际按账号后台判断。不要将测试广告播放成功等同于产生可结算收入。

**并行规则：**开发与手续可以并行；文化互动类版本审核须在资质审核完成后进行，其他类目按所提供指引可同时进行。类目必须与游戏实际内容一致。

## 三、个人注册与微信认证

### 个人注册

- 注册条件：年满18岁、具有中国大陆地区居民身份信息的微信实名用户。
- 按注册页要求准备符合条件的邮箱，完成邮箱验证、主体及管理员信息填写。
- 小游戏类目一旦设置成功，不得修改为其他一级类目。

### 个人微信认证

- 费用：**30元／次申请**，支付方式为微信支付。
- 认证审核费不以认证成功为前提；失败或撤回不应理解为可退费。
- 使用绑定认证主体本人银行卡的微信扫码，并完成人脸验证。身份验证动作本身不扣费，不代表整个认证流程免费。
- 职业认证为选填项。
- “填写发票”是腾讯为认证费用开具发票，不是要求个人向腾讯开票。
- **未确认：认证有效期、年审／续费周期及再次申请的具体规则。**

## 四、IAA资质要求

### 项目选择

- 按纯广告、不做内购的方向，选择“小游戏当前及未来均不需要开通虚拟支付”。该选项包含未来安排，应按真实产品计划选择。
- 支付资质选择“不申请支付资质”。这不等于不申请广告变现。
- 三级类目按实际玩法选择，不为减少材料而错选。

### 普通休闲游戏适用判断

用户提供的IAA资质表将棋牌、文化互动、角色类单独列出，主体类型标为“非个人”；其余类目一行的主体类型标为“all”。其余类目中：

- 游戏自审自查报告：线上确认。
- 内容一致性承诺函：选填。
- 软著、版号及有关授权等材料：表格列为选填，仍需结合具体内容判断。

**不能把这个结论推广为所有IAA游戏都不需要软著或版号，也不能把表格选填理解为不需要拥有素材版权。**

### 特殊材料要求

截图明确：IAA游戏备案遇到以下情况，需要提交《计算机软件著作权登记证书》或对应其他授权材料：

1. 游戏名称含英文或“软件”字样。
2. 涉及相关品牌、公众人物合作等。

因此，原创、纯中文名、无品牌合作的普通休闲游戏，不必先把软著代办费列为默认启动支出。最终材料以实际类目和后台要求为准。

### 提交入口与检查

- 入口之一：账号设置／小程序备案 → 小游戏备案及发布流程指引 → 资质提交。
- 入口之二：设置 → 游戏设置 → 资质管理。
- 保持游戏名称、主体、签署人等信息一致；个人材料避免混用“本人”和“我司”。
- 按要求签署并填完整日期，材料上传至对应模块。
- 资质审核通常为 **1～3个自然日**，不是全部上线耗时。

## 五、小游戏备案与小程序备案

两项备案是不同环节，不能只做其中一个。

| 环节 | 主要事项 | 截图预计时间 |
|---|---|---|
| 小游戏备案 | 场景、玩法、功能介绍及对应截图；签署文件、适龄提示；平台及主管部门审核 | 约10个工作日 |
| 小程序备案 | 前置事项完成后，填写并提交后续备案材料 | 3～10个工作日 |

另一份IAA流程截图给出的非虚拟支付路线从备案到发布预计为 **10～30个工作日**。以上是页面预估，不是保证时限，不能机械相加；补正、驳回及排队会影响进度。

### 重要约束

- 备案材料须真实、完整介绍游戏；截图保持尺寸和版本一致。
- 首次提交前确定正式游戏名称及主体。
- 小游戏备案提交后处于审核中或审核通过状态，至小程序备案完成前，不允许修改名称或主体。
- 平台审核中若需要修改备案信息，可按页面指引撤回、修改并重新提交。
- 进入主管部门审核后，按指引等待，不修改名称或迁移主体。
- 完成备案后发生名称、主体等相关信息变化，需要同步更新备案信息。
- **现有备案截图未列收费，不据此断言所有备案相关支出均为零。**

## 六、流量主开通条件

官方广告开通截图说明：**以下任一条路径满足即可**，每条路径内部的条件需同时满足。

| 路径 | 条件 | 对个人首作的适用性 |
|---|---|---|
| 条件一：累计访客 | 累计独立访客UV **>500**；无刷粉行为且未曾有严重违规记录 | 可用 |
| 条件二：游戏圈 | 开通内置游戏圈并产生有效活跃，即用户从小游戏内进入游戏圈产生内容消费、转评赞等行为；发布5篇官方帖子 | 可优先评估 |
| 条件三：同公司已有产品 | 同公司已有小程序开通流量主，并符合持续一个季度变现、无历史流量主违规等条件；迁移主体另有等待建议 | 不作为个人首作路径 |

- 入口：微信公众平台后台 → 功能 → 流量主。
- 访客路径达到条件后，资格需要次日刷新，可次日再次尝试。
- 游戏圈路径不是“发5篇帖子即可”，还须满足有效活跃要求；截图未明确人数、时长或次数阈值。
- 不能通过刷访客、刷互动或无效广告行为凑条件。
- 页面没有列出必须充值买量或广告开通费。
- 广告开通资格、广告接入成功、正式收入和实际收款是不同阶段。

## 七、广告收入与推广激励

用户提供的《2026年微信小游戏广告变现激励政策》说明自2026年8月20日起调整方案。

- 普通方案表格列有 **50%现金激励**，实际结算及到手金额仍受具体规则、有效数据和税费影响。
- 买量等指定渠道的35%／40%等激励属于 **广告金**，用于广告投放，不能算作可提现现金。
- 纯IAA买量注册激励表格列有“1～30天40%”或“1～180天35%”选项，并有适用用户及累计活跃时长要求。
- 广告金通用规则写明T+2结算发放、365天内使用；这是广告金规则，不是现金到账周期。
- “累计活跃超过3分钟”是相关推广激励条件，不是流量主开通门槛。
- 页面顶部新政策及表格与后文部分“日活跃超过5分钟”表述不一致，参加具体激励前需核实。
- 创意小游戏另有认证及特殊计算规则，不自动适用于普通首作。

**首阶段不需要购买推广服务。**可先获取真实试玩用户，跑通广告接入和收入记录，再评估是否扩大投入。

## 八、个人结算

依据用户提供的《微信公众平台广告展示服务协议》第4条截图：

| 项目 | 协议内容 |
|---|---|
| 个人收款 | 明确规定个人结算；银行账户户名应与注册主体名称一致 |
| 通用结算周期 | 每自然月结算一次；不同流量位可有具体计费及结算规则 |
| 账单确认 | 每月20日前确认上一自然月金额；异议在25日前提出，节假日顺延 |
| 到账金额 | 结算金额扣除适用的代征、代扣税费后，支付至银行账户 |
| 发票 | 企业条款要求提供发票；个人条款说明腾讯代征、代扣税费，未要求个人按企业流程开票 |
| 年度税务事项 | 协议写明个人自行履行年度个人所得税综合申报义务 |

**注意：**20日是账单确认期限，不是保证打款日；企业“收到合格发票后30个工作日内支付”的条款不能直接套用到个人。

仍待确认：小游戏具体结算周期是否有专门规则、最低打款金额、个人实际到账日期及收款账户填写要求。到广告开通／结算设置时核对，不影响先制作样品。

- [ ] 适龄提示的具体分级与展示要求。

- [ ] 小程序备案个人材料、短信核验及后台具体填写要求。
- [ ] 版本提审清单、包体与性能要求、真机兼容性。
- [ ] 激励广告播放完成才发奖励；取消、失败、重复回调及切后台处理。
- [ ] 测试版广告与正式可结算广告的规则，流量主最早申请阶段。
- [ ] 游戏圈有效活跃的实际判定及个人账号功能开放情况。
- [ ] 微信认证有效期、年审与续费规则。
- [ ] 个人最低打款金额、具体结算与到账安排。

## 十、当前执行建议

1. 先确定一种核心玩法及正式命名方向，核对类目。
2. 使用同一Cocos项目做目标平台真机可运行的小版本，不另做需要抛弃的技术样品。
3. 尽早核实隐私、实名／防沉迷及必接能力，避免临上线补基础功能。
4. 内容基本确定后，准备真实截图、说明及相应材料，办理审核和备案。
5. 按账号条件选择流量主路径，完成广告接入后测试并发布。
6. 以真实玩家、有效广告收入和实际维护耗时评估副业价值，不把广告金当现金、不提前买量。
